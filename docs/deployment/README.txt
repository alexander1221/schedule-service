СЕРВИС РАСПИСАНИЯ — РАЗВЁРТЫВАНИЕ И СОПРОВОЖДЕНИЕ
Документ 1.0 от 10.11.2026. Приложение 0.14.0, ветка work.

Начните с deployment-guide.pdf, deployment-guide.docx или deployment-guide.md.
Для существующего сервера сначала изучите паспорт и раздел управления.
Не перезаписывайте .env и не удаляйте тома ради устранения ошибки.

Состав: инструкция в трёх форматах, README, скрипт копирования,
отдельный Compose для проверок, Dockerfile проверок, тесты backup-скрипта,
сборщик документов и SHA256SUMS.txt. Исходного кода приложения в ZIP нет.

Файлы комплекта размещаются в docs/deployment/ внутри репозитория.
Тестовый проект schedule-check отделён от рабочего. Параметры сервера
не выдуманы: их необходимо заполнить и проверить с администратором.

Архивы, созданные schedule-backup.py, содержат базу и секреты,
НЕ зашифрованы и не предназначены для GitHub или публичной отправки.
Успешная проверка архива не заменяет пробного восстановления.

Подробный состав, команды и ограничения — в README.md и руководстве.
