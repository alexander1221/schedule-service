# Работа диспетчера: семестр от начала до готового расписания

Все действия — в админке (`/admin/`). В строке семестра в списке «Семестры» есть ссылки:
«Проверить», «Нагрузка ⇣/⇡», «Справочники ⇣/⇡», «Пожелания».

## 1. Семестр

«Семестры» → «Добавить»: название, дата начала, **дата окончания занятий** (до неё повторяются
события в календарях), чётность первой недели, учебная ли суббота, **срок сдачи пожеланий**.
Курсы 1–4 и сетка пар создаются сами, время пар можно поправить в карточке семестра.

Правила в карточке семестра:
- **«Учитывать вместимость»** выключено по умолчанию: посещаемость не 100%.
- Минимум пар в день приезда преподавателя (по умолчанию 2).
- Лимиты пар в день.
- Окно между очной и онлайн-парой (по умолчанию 90 минут).

## 2. Справочники и нагрузка

- **Первый раз** — из файла текущего расписания: «Семестры» → «Черновик из текущего расписания».
  Получите три файла. Проверьте лист «Что проверить» в `report.xlsx`. Затем загрузите
  `references_draft.xlsx` через «Справочники ⇡» и `workload_draft.xlsx` через «Нагрузка ⇡».
- **Дальше** — правка в Excel по кругу: «⇣» скачать, поправить, «⇡» загрузить. Сначала всегда
  с галочкой «Только проверить»: покажет ошибки с номером строки и колонки, ничего не записав.
  Строки нагрузки с ID обновляются, а не дублируются.
- **Площадки.** У ВДНХ закрытие в 21:00. Пары, которые заканчиваются позже, на площадке не
  ставятся. Исключение — занятия с флажком «можно закончить раньше» (киноклуб).
- **Ручные занятия.** Кружки и элективы — «Кто ставит: вручную», пары задаются в колонке
  «Закрепления» («Пт 6 (Ц1 301)»).

## 3. Пожелания преподавателей

1. Впишите почту в карточку преподавателя или в колонку «Почта» в справочниках.
2. В списке преподавателей отметьте нужных → действие **«Разрешить вход по почте»**.
3. Разошлите ссылку `https://<адрес сайта>/login/`. Преподаватель входит по коду из письма и
   заполняет сетку −2…+2 до срока сдачи.
4. Кто сдал, а кто нет — ссылка **«Пожелания»** в строке семестра.

За преподавателя без почты пожелания вносит диспетчер: карточка преподавателя или лист
«Доступность» в справочниках.

## 4. Проверка и расчёт

1. **«Проверить»** в строке семестра. Красные ошибки нужно исправить: с ними расписание заведомо
   не построить. Подсказки (потоки, «через неделю», бронь аудитории) применяются действиями в
   списке нагрузки, фильтр «подсказки».
2. **Расчёт.** В терминале выполните
   `python manage.py solve_semester <номер семестра> --time 300 --variants 3`.
   На сервере то же самое через `docker compose exec web …`. Номер семестра виден в адресной
   строке, когда открыта его карточка.
3. **«Варианты расписания».** У каждого варианта есть:
   - сетка по группе, преподавателю или аудитории;
   - свободные аудитории;
   - часы к табелю.

   Если вариант почти устраивает, закрепите нужные пары и пересоберите с минимальными
   изменениями: `solve_semester <номер> --reference-variant <номер варианта>`.

## 5. Утверждение и публикация

1. В списке вариантов отметьте лучший → действие **«Утвердить»**. После этого преподаватели видят
   своё расписание на странице «Мои пожелания» и могут подписаться на календарь.
2. **«Excel ⇣»** в строке варианта: файл с листами «Группы», «Преподаватели», «Аудитории» для
   публикации и печати. Если по чётным и нечётным неделям занятия разные, в ячейке написано
   «нечёт: …» и «чёт: …», и она выделена цветом.
3. Календарь любой группы, преподавателя или аудитории: на странице «расписание» варианта выберите
   нужное и нажмите «Календарь .ics (выбранное)».

## 6. Если что-то пошло не так

| Ситуация | Что делать |
|---|---|
| Проверка показывает ошибки | Текст ошибки говорит, что исправить: элемент нагрузки, группа, преподаватель |
| Решатель: «нет допустимого расписания» | Внизу вывода — какие требования противоречат друг другу (запреты преподавателя, закрепления, блоки) |
| Преподаватель не может войти | Почта есть в карточке? Нажато «Разрешить вход по почте»? Журнал «Коды входа» — был ли отправлен код |
| Нужно вернуть прежние данные | Резервная копия — у администратора (docs/DEPLOY.md, раздел 5) |
