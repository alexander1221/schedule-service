# Форматы xlsx

> **Шаблон нагрузки временный.** Он придуман до получения образца таблицы учебного отдела.
> Колонки сопоставляются по заголовкам, порядок неважен — подстройка под реальный формат
> сводится к правке словаря `COLUMNS` в `timetable/xlsx/workload.py`. Пришлите образец
> (можно с вымышленными ФИО) — шаблон будет переделан под него.

## Общие правила импорта

* **Всё или ничего.** При любой ошибке не записывается ни одна строка. Ошибки показываются
  списком «лист — строка — колонка — что не так», с подсказкой похожего названия при опечатке.
* **Пробный прогон** (галочка «Только проверить», по умолчанию включена) показывает, что
  изменится, и ничего не пишет.
* Порядок колонок любой; лишние колонки пропускаются с предупреждением; пустые строки
  пропускаются. Названия сравниваются без учёта регистра, «ё/е» и лишних пробелов.
* Самый надёжный способ: **скачать текущие данные, поправить в Excel, загрузить обратно**.

## Нагрузка (`Нагрузка ⇣/⇡ xlsx` у семестра)

Лист **«Нагрузка»**:

| Колонка | Обязательна | Значения |
|---|---|---|
| ID | нет | номер элемента; пусто — новая строка; у существующих не менять |
| Дисциплина | да | из справочника дисциплин |
| Вид | нет (практика) | лекция / практика / лаба (понимает и «лек», «пр», «лабораторная») |
| Преподаватели | да | ФИО или почта; несколько — через «;». При одинаковых ФИО — почта |
| Группы | — | названия через «;»; несколько — поток |
| Подгруппы | — | «Группа: подгруппа», при неоднозначности «Группа: деление: подгруппа» |
| Пар за 2 недели | да | 1–28; 3 = одна каждую неделю + одна мигающая (понимает и «Пар за цикл») |
| Формат | нет (очно) | очно / онлайн |
| Тип аудитории | для очных | название или код типа |
| Численность | нет | для языковых подгрупп блока |
| Схема недель | нет (обычная) | обычная / через неделю — все пары в одну неделю из двух, по две подряд (кино) |
| Бронь аудитории | нет | да / нет — онлайн, но преподаватель ведёт с площадки (нужен тип аудитории) |
| Кто ставит | нет (решатель) | решатель / вручную — элективы и кружки; решатель учтёт их, когда все пары закреплены |
| Можно раньше | нет | да / нет — занятие можно закончить раньше, к закрытию площадки (киноклуб): ему разрешена 7-я пара на ВДНХ, «до 21:00» (0.4.1) |
| Закрепления | нет | «Пт 6; Пт 7 нечёт; Ср 2 (Ц1 301)» — день, пара, при желании неделя (чёт/нечёт) и аудитория в скобках. Пустая ячейка снимает закрепления; если колонки нет, закрепления не трогаются (0.4.1) |
| Сдвоенная | нет | да / нет |
| Приоритет | нет | целое |
| Синхронный блок | нет | название блока; новый блок создаётся |
| Объединение | нет | название допустимого объединения; одинаковое у объединяемых строк |
| Подпись | нет | например «B1» |
| Комментарий | нет | любой текст |

Участник обязателен: группы, подгруппы или синхронный блок. Если в файле нет колонок «Схема
недель», «Бронь аудитории», «Кто ставит» (шаблон до 0.3.0), их значения у элементов не меняются.

Лист **«Блоки»** (необязательный): «Синхронный блок» | «Группы» (через «;») — какие группы
распускаются в блоке. Лист **«Справка»** — пояснения; скрытый лист «Списки» — источники
выпадающих меню.

Режимы загрузки: «добавить и обновить» (по умолчанию) и «как в файле» — дополнительно удаляет
элементы семестра, которых нет в файле.

## Справочники (`Справочники ⇣/⇡` у семестра)

Импорт только **добавляет и обновляет**, ничего не удаляет. Листы можно присылать не все.

| Лист | Колонки | Ключ поиска |
|---|---|---|
| Преподаватели | ФИО, Почта, Работает, Макс. пар в день, Лимит жёсткий, Нужно оборудование, Предпочитает аудитории | почта, иначе ФИО |
| Оборудование | Код, Название | код |
| Дисциплины | Название, Сложность, Кафедра | название (новая кафедра создаётся) |
| Типы аудиторий | Код, Название | код |
| Аудитории | Номер, Корпус, Вместимость, Тип, Используется, Оборудование, Примечание | номер |
| Группы | Название, Курс, Численность | название в семестре |
| Подгруппы | Группа, Подгруппа, Численность, Деление | группа + деление + подгруппа |
| Доступность | ФИО, Почта, «Пн 1» … «Пт 7» (по сетке семестра) | почта, иначе ФИО |

В «Доступности» пустая ячейка = 0 «всё равно»; допустимы −2…2. Лист «Занятость аудиторий»: Номер,
Кем занята, «Пн 1» … — «x» в занятых парах. Оборудование и аудитории в списках — через «;», по
названию или коду; неизвестное — ошибка с подсказкой.

## Черновик из текущего расписания

Файл, в котором учебный отдел ведёт расписание сейчас, понимается в таких разрезах:

| Лист | Что берётся |
|---|---|
| «Аудитории …» | A — аудитория, B — свойство («компы», «лекционка», «компы (ПО Джава)»), «26к» — число компьютеров |
| «Группы …» (ПиУП) | ячейка «дисциплина / преподаватель / группы / аудитория», «ОНЛАЙН», «МИГАЮЩАЯ»; английский — «Фамилия (аудитория)» по строкам + строка групп |
| «Расписание Кино» | «Дисциплина  Фамилия Имя», аудитория — в соседней колонке; «ЧЁТНЫЕ/…» — две дисциплины через неделю |
| «Преподаватели», «Англ …», «… возможности» | список фамилий — помогает отделить преподавателя от дисциплины |

Результат — `references_draft.xlsx`, `workload_draft.xlsx` (наши шаблоны) и `report.xlsx` («Что
проверить»: не распознан преподаватель, несколько аудиторий в ячейке, аудитории нет на листе, похожие
фамилии, условные названия групп). Численность групп (25) и вместимость (по числу компьютеров или 25)
в исходном файле отсутствуют — это значения по умолчанию, их нужно уточнить.
